# Deploying JMC Classroom to Vercel (https://class-jmc.vercel.app)

This project is pre-configured for instant **Drag and Drop** or **Git / CLI** deployment to **Vercel** under the domain `https://class-jmc.vercel.app`.

---

## Method 1: Vercel Drag & Drop Deployment (Easiest)

1. Open your browser and navigate to:
   👉 **[https://vercel.com/new](https://vercel.com/new)**
2. In the deployment area, **Drag and Drop** either:
   - The entire project root folder, **OR**
   - The compiled `dist/` folder (generated by running `npm run build`).
3. Vercel automatically detects:
   - **Framework**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Routing & Rewrites**: Loaded from `vercel.json` (prevents 404s on browser refresh).
4. Click **Deploy**.
5. Once deployed, assign your custom domain in **Project Settings -> Domains**:
   - Add domain: `class-jmc.vercel.app`.

---

## Method 2: Vercel CLI Deployment

From the terminal in the project directory:

```bash
# 1. Build the production assets
npm run build

# 2. Deploy directly to production on Vercel
npx vercel --prod
```

---

## Critical Post-Deployment Steps

### 1. Add `GEMINI_API_KEY` to Vercel
If you want to use the AI Lesson Assistant and JMC AI Tutor features:
1. Go to your Vercel Dashboard -> Select project **class-jmc**.
2. Go to **Settings -> Environment Variables**.
3. Add a new variable:
   - **Key**: `GEMINI_API_KEY`
   - **Value**: Your Google Gemini API Key
4. Redeploy or trigger a build.

### 2. Allowlist Domain in Firebase Authentication
For Google Sign-In to function on `https://class-jmc.vercel.app`:
1. Open the [Firebase Console](https://console.firebase.google.com/) for project **`jmc-class`**.
2. Go to **Authentication -> Settings -> Authorized domains**.
3. Click **Add domain**.
4. Enter: `class-jmc.vercel.app`.
5. Click **Save**.

## File Structure for Vercel
- `vercel.json`: Root Vercel configuration for SPA routing rewrites and API serverless functions.
- `public/vercel.json`: Copied directly to `dist/vercel.json` so dragging `dist/` directly also preserves SPA routing.
- `api/ai/lesson-assistant.ts`: Vercel Serverless Function for AI curriculum generation.
- `api/ai/study-helper.ts`: Vercel Serverless Function for student AI explanations.
- `index.html`: Production HTML entry point with canonical tags for `https://class-jmc.vercel.app`.
